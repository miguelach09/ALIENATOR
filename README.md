ALIENATOR


Kethris-9 is a rogue moon fused to a dead gas giant. Inside, The Array is active—an alien machine that ceaselessly churns out defenses. You have been dropped into its depths from orbit. You have 12 defense pulses to reclaim the moon and reach the extraction elevator.

It is a wave-based arena first-person shooter with a blocky aesthetic.

Controls


WASD — move

MOUSE 1 — shoot / MOUSE 2 — aim down sights

SPACE — jump (press again in mid-air to double jump)

SHIFT — dash: brief invulnerability, used to dodge attacks

CTRL — crouch (hold while running to slide)

1 / 2 / 3 or scroll wheel — switch weapon • R — reload

V — third-person view • ESC — pause (settings for sensitivity, FOV, volume, screen shake…)
